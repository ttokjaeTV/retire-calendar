# 노후 월급 달력 · 똑재TV

국민연금, 연금저축·IRP 인출, 일반계좌 배당(월배당·분기배당 ETF)을 합쳐 은퇴 후 1~12월에 달마다 통장에 들어오는 돈을 보여 주는 계산기. 연금소득세·배당 원천징수를 떼고, 가장 적은 달·많은 달, 생활비보다 모자란 달, 빈 달을 채우는 분기 배당 시기(1·4·7·10 / 2·5·8·11 / 3·6·9·12월)를 알려 준다.

- 사이트: https://ttokjaetv.github.io/retire-calendar/
- 제도 숫자는 허브 `rules/v2026.3/rules.js`의 `PENSION`(나이별 연금소득세, 1,500만원 기준), `FIN_INCOME`(15.4%·미국 15%, 2,000만원), `NHIS.finIncomeThreshold`(1,000만원)에서 읽는다.
- 국민연금은 입력한 실수령액 그대로, 연금계좌는 받는 날 만 나이 세율(세액공제 받지 않은 원금만 꺼내면 0원), 배당은 일반계좌만(ISA·연금계좌 배당은 계좌 안에 쌓임).
- 넣지 않은 것: 국민연금 소득세·건보료·물가 인상, 연금 1,500만원 초과 시 종합/분리과세, 이연퇴직소득 세금, 금융소득 종합과세·건보료(경고만), 배당 변동·환율.

## 수정하는 법
`src/`를 고친 뒤 `python src/build.py` → `index.html`. 시험 `node src/test.js`(기대값은 손계산).
